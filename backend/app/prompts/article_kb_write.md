# 硬红线（违反即整稿作废）
1. 全部事实、案例、数字只来自【素材】；素材没有的不写，不许外推补细节。
2. 全文禁止出现：知识库、素材、检索、收录、来源、文档等任何生产过程词汇。
3. 案例以行业事实口吻第三人称叙述（「某企业…」「有家企业投入三十万元…」）；素材中标注为自有交付资产的内容可用「我们的做法」，其余不得写成第一人称亲历。
4. 「不是X，而是Y」式对仗全文至多一处；单句成段至多一处；不用加粗论点加冒号的要点句式；不用「综上所述」「由此可见」「说到底」类连接词；不用金句收束；不用「最X的一种」式平行小节标签。
5. 不套固定骨架：章节编号（01/02/03）只在论证本身需要排序时才用；小节标题直陈该节内容；段落长短错落，同一观点只说一遍；生活化类比全文至多一个。
6. 对照类干货用 Markdown 表格承载；机制与动作写成正常段落，不要列表化排版。

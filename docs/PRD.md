# PRD · Product Requirements（产品需求）

> 本文件是"产品必须做什么"的唯一权威出处，只写预期。
> 用语：**做** = 必须实现；**不做** = 明确排除；**边界** = 平台/技术边界内给替代路线。

## R0 总纲

- **R0.1** Web 应用·单管理员：浏览器直接可用的界面（不做 CLI），登录门禁 +
  凭证平台统一配置（R9；多租户/积分/成员体系不在系统范围）。单机部署起步，架构不锁云。**做**
- **R0.2** 业务范围 = 六个模块：**素材库 / 人设号 / 获客号 / 公众号 / 小红书 / 数据**。
  「今天 / 任务 / 设置 / 认证」是服务六模块的平台能力，不是第七个业务模块。**做**
- **R0.3** 生产边界：内容线止于**稿件与图文物料**（口播视频稿、公众号长文、小红书图文笔记）；
  视频成片、数字人、剪辑、发布台物料包不在系统范围。**不做**
- **R0.4** 发布方式：默认**人工发布**；**公众号支持官方 API 发布**——人工点按触发建草稿/群发，
  失败可回退人工复制粘贴；**不做无人值守自动群发**。抖音、小红书、视频号一律人工发布。
  AI 辅助生成的内容发布时勾选「AI 生成」声明（《人工智能生成合成内容标识办法》合规）。
  **发布排期（2026-11-22 R3）**：定稿可人工设计划发布时间（payload.publish_plan，数据页「排期」
  tab 日历管理）；发布登记后排期作废。**做**
- **R0.5** GLM 为主 LLM（写作模型可切换），单通道、不保留备选 LLM 通道开关。**做**
- **R0.6** 内容定位：FDE 三条业务线（企业主 AI 培训获客 / FDE 项目交付 / FDE 人才培训），
  每条内容落到"可验收"视角；周节奏 **5 条+ 口播短视频 + 2 篇+ 公众号长文 + 小红书笔记**；
  业务线**交付项目优先**；主战场**抖音优先**，小红书为独立经营渠道，视频号同步但无自动扫描；
  **不刻意做 CTA**（人设线转化自然发生；获客线按 R3 纪律显式引导）；
  **能用里程碑 = 带来第一个真实客户线索**。**做**
- **R0.7** **素材库是唯一进料口**：知识库、同行监控、话题雷达、站外热点、一手实测/案例/图片
  统一入素材库；四条内容线只从素材库取料，不各自采集。**做**
- **R0.8** 四条内容线共用一条生产引擎：**素材 → 选题 → 稿件 → 发布登记 → 数据回流**；
  渠道差异只落在取料规则、提示词、合规红线、产物形态、发布方式与指标口径。**做**
- **R0.9** 能复用开源就不自研。**做**

## R1 素材库

- **R1.1** **统一素材对象**：一条素材 = 一个可被内容线消费的具体原料——
  抖音视频/图文、公众号文章、网页、知识库文档、音频、图片、一手实测记录、案例/口述。
  素材字段含：来源类型、来源平台、来源链接/平台 ID、作者、标题、正文/转写、媒体、互动数、
  标签、质量信息、采集时间、发布时间、状态、去重哈希。**做**
- **R1.2** **素材边界**：素材 = 外部原料 + 一手自有素材（实测结论、客户案例、现场图片/口述）；
  **成稿不进素材库**——口播稿、长文、笔记属于各内容线产物；跨渠道复用成稿走「内容引用」，
  不把成稿伪装成素材。**做**
- **R1.3** **采集源管理**：同行账号、话题雷达、知识库目录、站外热点源、手动上传五类源；
  源可增删改查、启停、记录上次同步；同行账号支持链接自动识别、质量评分与移除建议；
  关键词发现/同城矩阵产出的账号先入**候选**，人工定夺后转正式采集源。**做**
- **R1.4** **入库与定夺**：采集结果先入**收件箱**（inbox），不做入库前人工筛；
  人工只做「可用（ready）/忽略（ignored）」定夺；质量闸可把明显不合格项自动标 ignored
  （闸线与原因可见，可手动翻案）。**做**
  （定夺视图=「素材库」页「素材池」tab；每日取料两条产线在「今天」页（热门评论→口播 / 知识库→长文图文），
  2026-11-18 用户定版：今天=取料，素材库=源·池·库）
  **晨报决策队列/行动清单（2026-11-22 R1）**：今天页晨报加两块——决策队列=要我审的
  （口播稿/笔记稿待终审、选题卡待备稿、素材收件箱，计数+样例+直达）；行动清单=要我做的
  （该发布=定稿未登记、该补录=发布超 48h 未回流、近 7 天判卷结果）；数据源=/stats/briefing。
  **灵感随手存（2026-11-22 R4）**：选题页一句话手动建卡（POST /api/cards，source=manual，
  hook/spine 备稿时补填）。**发布节奏块（2026-11-22 R3）**：三线本周实发 vs 周目标（AppSetting publish_targets，设置页
  可调，0=不限），落后标红——晨报从「报数字」升级为「报偏差」。
- **R1.5** **素材加工**：视频自动转写、拆解分析、高赞评论原文存档、
  评论区分型（人设矿 / 获客矿：求学打卡占比 ≥`comment_leadgen_route_min` 默认 60% 判获客矿）、
  热度分（评论/2+赞/60 封顶 10）；分析结果按版本留痕；拆解闸=评论 ≥20 或 赞 ≥300；
  **评论补采**（2026-11-18）：拆解时评论抓取只此一次且成功率低（~5%），失败由独立补采批量任务
  重试——监控清单作者优先、按互动降序、视频间静默窗防风控、连败 3 次停采；补采成功与拆解
  同口径落档（评论存档+分型+账号联动改判），light 分道跑不堵生成任务。**做**
  **拆机制五问+借不借三关（2026-11-22 P2）**：对标拆解输出加 teardown 五问（第一句靠什么停/
  钩子被什么接住/吸引力类型/人群宽度/结尾给的理由）与 borrow_check 三关（复读关口吻/客户关
  价值/替换关落地条件）——拆机制不拆句子；五问三关透传口播热点模式素材块与素材详情页。**做**
  （设置页可调，播放数匿名拿不到不进闸线）。**做**
- **R1.6** **检索与引用**：按全文、标签、来源类型、作者、状态筛选；
  素材详情显示「被哪些选题/稿件引用」；引用关系只做**追溯**，不做效果归因（R6.6）。**做**
- **R1.7** **存量回填**：话题侧把精选集按追溯窗回填；账号侧把追溯窗内作品翻一遍；
  追溯窗=设置项 `backfill_window_days`（默认 30，可调到 90）；**匿名列表深度天花板 ~15 条/账号**，
  90 天深度只有登录态（自有账号）可达；回填过闸才入库，避免空耗拆解。**做**
- **R1.8** **账号候选**：关键词发现（搜索引擎→视频链接→反查作者）与同城搜索矩阵
  （城市×关键词→作者池→取证→LLM 分级）产出候选；候选永久去重，人工定夺后加入采集源。**做**
- **R1.9** **来源与合规**：每条素材保留来源/作者/链接/抓取时间；国内数据源优先；
  引用外部内容必须改写判断与表达，不做原样搬运；素材只在本系统内部消费，不二次分发。**做**

## R2 人设号

- **R2.1** **定位=观点怼热点**。三原则（选题与脚本共同的法律）：
  ①**三秒钟原则**：前三秒是吸引力装置，观点说清楚是底线、抓住人是目的
  （钩子 ≤3 秒；字数线=3 秒×语速口径 5 字/秒=15 字，设置页可调）；
  ②**半句话原则**：整条视频的主线是一句半句话，全程展开论证它，但**理论上半句话不出口**
  （不进台词/字幕/收尾）——观众看完自己压得出来；
  ③**广度×热度原则**：域内（不脱离 AI 与 AI 落地）×广覆盖（主语人口盘子：老板>中层>岗位大盘）
  ×热度（此刻真有流量在流动）。**做**
- **R2.2** **选题工场**（每日 6 点，宁缺毋滥，无可怼=诚实空过）：
  - **进料**：一手·抖音原生（监控对标号新视频评论 ≥`pool_peer_min_comments` 默认 50，
    按评论实数降序取前 10；新鲜窗 `pool_peer_window_hours` 默认 72 小时〔2026-11-18 由 30
    调宽，让存量真矿进线〕；话题雷达飙升；抖音热点榜）＋**自有·一线交付**
    （实测结论/客户案例/客户口述——2026-11-18 用户裁决接通 self_story，每批 ≤3 条，
    主线只能从交付事实里抽）；对标圈素材禁当靶子；获客矿不归人设线（每批 ≤1 张
    「求学现象卡」做元角度口子）。
    **二手·外站五路 2026-11-18 停用**：二手热度结构性够不到流量线（实测 tp 恒 4-6 < 7），
    每轮陪跑 0 产出；榜单信号只留在公众号直出线。
  - **车间一·池子**：程序闸=域内证据非空 / 覆盖档非窄；一手免检热度，二手挂 secondary。
  - **车间二·主线锻造**：先从高赞评论原文抽**评论要点**（大众最强烈的关注点/痛感，≤3 条留痕），
    主线从要点长出来（共鸣=替大众说狠 / 错位=顶大众读法说），必须是评论区里没人说出来的那句话；
    无评论的池子素材撑不起就跳过；主线闸=15 字线+14 天撞车+批内去重。
  - **车间三·钩子铸造**：输入带「评论要点 + 前三条高赞评论」（2026-11-18 用户裁决：
    钩子的点名/数字/情绪从评论矿脉里捡，禁整句抄评论）；三秒闸=15 字线+劝告/悬念/引入词根拦；
    拆解库高分钩子做 few-shot。
  - **总法官**：钩子吸引力/主线单一/流量潜力三维，任一不过线=kill 落弃卡池；
    流量潜力按证据分档起评：平台实数 8 / 自有交付 7 / 二手 5（2026-11-18）
    （`jail_window_days` 默认 7 天可捞）；每日上限 `daily_card_limit` 默认 20 张。
  - **选题卡**（原「靶子卡」，2026-11-18 用户定名）四面：池子证据/主线/钩子/裁决记录；批次替代（当日无下游旧卡让位）；
    消费=定夺 → 备稿（钩子/主线可改+主打打法六选一）→ 脚本。
  - **校准回路**：周报出「选题卡→视频表现」对照表（模糊匹配，只对照不评分），
    参数由人看表人肉调。**做**
- **R2.3** **实测打假**：待实测清单（主张/对象/线索）——实测是物理动作，系统管清单与成稿；
  清单载体=「素材库 · 实测打假」tab（2026-11-18 用户裁决：清单是素材实体，不占选题页 chips）；
  工场每日尾段自动猎取 ≤3 条可实测主张（买得起/用得上/跑得完；纯观点争议归选题卡）；
  实测结论回填后才能成稿（独立实测稿模板：钩子=实测结果数字、中段只准用实测事实）。**做**
- **R2.4** **脚本**（一版精品直出，质量优先于选择）：按选题类型自动选范式；
  篇幅两档——**240~320 字（50~70 秒，默认）** 与 **600~900 字（2~3 分钟）**；
  硬约束=开场三秒逐字使用钩子（≤2 字口语化微调）、中段单判断推进且主线不出口、
  证明可验证（案例/数字/交付物）、结尾自然收束（不刻意 CTA、禁引导话术、不复述主线）、
  合规红线（禁绝对化承诺/夸大宣传）、人设回扣（证明环节落到可验收交付）；
  生成后自动先打磨一轮，仍可手动追加。**做**
  **口播选题第二车道（2026-11-18 用户定版）**：知识库文档只产公众号长文+小红书图文（不直出口播）；
  口播稿选题源=**监控清单作者与白名单话题（fde/企业ai落地/企业知识库）视频的高赞评论**
  （受众用赞投票的共鸣点；准入线=`hot_comment_bar` 默认 50 赞；每视频存档按赞前 40 条，
  存档 7 天滚动刷新）→ 一键成稿：**三道门（真事/能点名的对象/我的判断）**，
  过不了直接跳过、不建稿；照号主爆款写（第一句开火、一条只讲一个故事、结尾停在半句话、
  只用素材原话和数字禁编造）；**形态读稿闸**（代码机械判：均 ≤13 字/单句 ≤20 字/零书面标点，
  标尺=号主真实爆款转写；不过带数字定向重写一次）；热评支持**逐条删除**（只从该视频评论存档
  摘掉这条，雷达不再出现；视频素材本身保留）。**热评预筛（2026-11-20 阶段 1）**：三道门前移
  到选题层——预筛任务判四档（doable 可成稿 / no_story 无真事 / no_target 点不出对象 / dup
  同事件重复），雷达页 doable 与未筛的在前、其余灰掉带大白话原因、不给生成按钮；同一对象同一
  事件 7 天内不重做。**口播判卷（2026-11-20 阶段 1）**：发布登记 ↔ 创作者中心回流联表，
  视频稿页展示播放/赞/评；播放 ≥3 万（=范本收割线）标「已进爆款范本库」。
  **去AI味机检（2026-11-22 太上老君框架 P1）**：生成收尾代码机检（假对比/空开场/自嗨开场/
  旁白腔/伪深度路标/商务腔/填充词密度/引用块自动豁免），命中落红提示（不拦发布）；
  提示词=全局底线（不编/钩子兑现/借机制不借句子/推断标明/不承诺流量）+AI味三禁五件套
  +改稿六刀自检（开头画饼→定性反差/自嗨设问删/名词减法/旁白腔/比喻去文青/金句落地就停）。
  **两步改编选题会接回（2026-11-21 阶段 2）**：KB 页「公众号长文」方向默认先开选题会——
  源文抽 5 个现场（scene/thesis/≤24 字标题/证据原文），人选定后改编只喂该现场证据包、
  标题优先用现场标题；可重掷换一批、可跳过按文档角度整篇改编。发布节奏 2~3 篇/周全垂直。
  **范本库可视化+判卷线可调（2026-11-22 R2）**：范本库=viral_gene_samples（self_scan 收割
  ≥收割线自有视频，JSON 存储），脚本工场页卡片可见、热点口播自动 few-shot 注入（收割线=
  judgement.viral_play() 单一真源）；判卷线六条（抖音爆款/过线、小红书爆文/过线、公众号优质/
  合格）设置页可调（AppSetting judgement_lines 覆盖，PUT 即生效，判卷/收割/晨报同步跟线）。
- **R2.5** **定稿三产物**：提词器文本（`/` 停顿、`**` 重音、按呼吸分段）、
  分镜（≥3 镜头含 B-roll 关键词）、标题候选（抖音×2 / 视频号×1 / 封面大字≤12 字）。**做**
- **R2.6** **发布登记**：人工发布后登记链接/时间；数据由 R6 回流。**做**

## R3 获客号

- **R3.1** **获客选题=获客矿素材流**：素材库中评论区分型为获客矿的视频按互动实数成列；
  展开=求学评论原文需求清单（什么课/什么资料在被求）；行上建稿=从该需求直接进获客脚本生成，
  不经过人设线选题工场。**做**
- **R3.2** **获客脚本纪律**：强制获客引导——结尾行动指令 + 利他包装的扣字/私信设计；
  合规红线仍约束产品承诺；可读投放账号类型默认获客号。**做**
- **R3.3** **发布与线索**：人工发布；发布登记后回填线索数（加微/私信/进线），
  线索作为经营指标进 R6 事实表，不建线索 CRM。**线索台账（2026-11-22 R1）**：获客页顶部
  累计线索+按稿明细（数据源=/analytics/publications）。**做**

## R4 公众号

- **R4.1** **每日热点直出**：每晚 0 点站外热点×画像提炼**唯一一个**最锐切角建 1 篇草稿，
  自动链发成文——早晨草稿箱里是一篇完整长文；热点须过**双锚**
  （受众锚：不懂技术的实体老板/转行普通人看得懂用得上；主题锚：必须长在 AI 与 AI 落地上），
  没有值得写的题允许空过（宁缺勿滥）。**做**
- **R4.2** **源文改编流**（系统做全部工作，用户只做两端决策）：

  （开场模式/句式节奏/口头禅/语气强度/论证习惯/收尾方式/代表原句）；滚动汇总为版本化画像
  （摘要+标签+代表原句+基于 N 条）；每新增 ≥5 条自动重算，可手动触发；
  脚本/笔记生成注入最新画像（可按次关闭，无画像回落内置人设并显式提示）；
  画像按渠道版本化，历史可回溯。**做**

## 非需求（明确不做）

- 抖音/小红书/视频号自动发布；公众号无人值守自动群发（R0.4/R4.5）。
- 视频号自动扫描（平台边界：无公开网页接口，只支持本地上传/人工）。
- 视频成片/数字人/剪辑/发布物料包（R0.3）。
- 移动端原生 App/独立客户端（移动能力仅 R10 轻量 Web 页）。
- 多租户/成员/角色/积分/成本台账（R9.2/R8.5）。
- 素材/内容效果归因、线索 CRM（R6.6）。
- 租户自带 LLM 凭证（R9.2 凭证平台统一）。

## 使用场景（产品怎么被用）

**核心心智**：打开今天看欠账 → 点卡片进队列 → 按键清空 → 表格里查历史。

### 日常工作流（建议节奏）

```
① 素材库自动采集（同行扫描 / 话题雷达 / 知识库挖掘 / 站外热点）→ 收件箱定夺
② 人设号：每日 6 点选题工场产选题卡 → 今日定夺 → 一键备稿 → 脚本一版精品直出 → 定稿三产物
③ 获客号：获客矿成列 → 展开求学需求 → 建稿 → 获客脚本 → 定稿
④ 公众号：0 点热点直出 + 4/5 点源文改编 → 改稿渲染 → 复制/API 发布 → 48h 回流
⑤ 小红书：素材库发起选题 → 笔记稿 + 封面模板 → 人工发布 → 数据回填
⑥ 数据：看板/周报复盘 → 调素材采集与选题参数
```

### 统一交互契约（X1 的用户视角）

- 队列快捷键：脚本 `A定稿、P打磨、S跳过`；其余页 `A主操作/S跳过`；全站 `Esc` 退出；
  输入框聚焦时自动屏蔽防误触。
- 慢操作有进度提示（定稿约 80 秒、打磨 3~6 分钟属正常）。

### 常见问题（FAQ）

| 现象 | 处理 |
|---|---|
| 在线拆解/扫描失败 | 可能触发验证码，重试；仍失败用本地视频拆解（失败原因在任务详情可见） |
| 公众号 API 发布失败 | 检查 AppID/Secret 与服务器 IP 白名单；回退复制 HTML 人工发布 |
| 小红书发布 | 无官方接口，一律人工发布，系统只做笔记稿与登记 |
| 数据缺回流 | 看板显式标「未回流」；按 R6.5 补录，不补零 |
| 测试假数据混入生产 | 冒烟一律走隔离实例（TDD §13）；生产侧对账走部署前快照与失败中台指纹 |

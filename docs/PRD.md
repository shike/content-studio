# PRD · Product Requirements（产品需求）

> 本文件是"产品必须做什么"的唯一权威出处，只写预期。
> 每条带编号与来源：D=初始六项决策 · C=开发中用户追加 · A=验收审计补齐。
> 用语：**做** = 必须实现；**不做** = 明确排除；**边界** = 平台/技术边界内给替代路线。

## R0 总纲

- **R0.1**（D6+C）多租户 Web 应用：浏览器直接可用的界面（不做 CLI），登录门禁 + 租户隔离 +
  凭证平台统一配置（详见 R11）；单机部署起步，架构不锁云。**做**
- **R0.2**（D2）范围 = 选题 → 脚本 → 视频 → 公众号 → 发布回流 全流水线。**做**
- **R0.3**（D1）公众号不自动发布；一切发布动作人工执行，系统只做物料与台账。**不做**
- **R0.4**（D5）GLM 为主 LLM（写作模型可切换）；DeepSeek 为备选通道。**做**
- **R0.5**（D3+C）视频剪辑**不做**：成片路线原为口播数字人（R10，2026-10-29 整体退役），不做剪映草稿/模板剪辑路线（用户裁定）。**不做**
- **R0.6**（D4）同行发现 = 自建账号扫描。**做**
- **R0.7**（C）能复用开源就不自研。**做**
- **R0.8** 内容定位：FDE 三条业务线（企业主 AI 培训获客 / FDE 项目交付 / FDE 人才培训），
  每条内容落到"可验收"视角；周节奏 **5 条+ 口播短视频 + 2 篇+ 公众号长文**（高产能设计）；
  业务线**交付项目优先**（内容优先展示交付案例拉项目询单）；主战场**抖音优先**、视频号同步；
  **不刻意做 CTA**（转化动作自然发生，系统不内置引导话术）；
  **能用里程碑 = 带来第一个真实客户线索**。
  每题双受众（企业主 boss / 准FDE fde / 双受众 both）。**做**

## R1 选题库

- **R1.1**（D）idea 深研：一句话 → 联网检索 → **深度研究报告（2000 字+，含更多案例与信源）**
  → 0-10 打分 + 钩子候选。
- **R1.1b**（C）快速记选题：不触发 LLM 的快速入库入口，事后可再深研。
- **R1.1c**（C）相似选题自动合并：同行拆解/多来源产生的相似主题候选，入库时自动检测
  与已有选题的相似度并标记/合并，减少重复入队。
- **R1.2** 全网热榜雷达（DailyHotApi/TrendRadar 类）。**不做**——大众热搜与本业务获客无关
  （用户明确否决）；"借势"的正确来源是**同行热门视频监控**（R3）。
- **R1.3**（D）同行视频拆解产出选题候选（钩子/叙事结构/可复刻点/选题价值）；候选标题与近 14 天已有选题相似 ≥0.55 时**不入库**（analysis 记 topic_candidate_suppressed）——不同同行视频产出同一角度是选题趋同的主通道（2026-10-10）。
- **R1.4**（C）**今日热点选题提炼**（2026-10-07 立项，2026-10-08 质量重构+领域锁定）：公众号页
  一键或每日 7 点自动（调度 trending_daily，示例租户）——**五路原料**（国内科技/AI 资讯=爱范儿+
  IT之家 RSS 近 48h=领域主力 · 百度热搜今日榜免登录抓取=泛热点仅强结合可选 · 联网检索=按画像+
  资讯生成的 3~4 条**领域内**查询词逐条检索，国内源优先 · 对标圈近 2 天新视频=议题参考禁止当
  热点 · 近 7 天已出题热点=禁写清单）× **租户画像**（persona/受众域）→ LLM 提炼 ≤3 个"今天可写"
  的**领域内**选题切角（内容四支柱轮转：欲望钩子常驻+干货切片/信任打假/交付背书按日轮换，2026-10-12 课程定位定版；切角带 evidence.pillar），过四层程序化硬校验（对标圈拦截/7 天热点去重/批内去重/**14 天选题标题防撞车**）落选题库
  （source_type=trending，draft），前端切角卡挑选后一键以 feed 公众号版生成长文。切角标准：
  **绑领域（泛社会/财经热点硬结合不了就不选，硬凑商业解读=废稿）**×绑真热点（hotspot 必须带
  日期，旧闻不写）×三切角三条热点（宁缺毋滥）×绑画像×绑受众；热点事实只用原料，不足就如实
  标注；任一原料路失败降级且可见。**批次替代**：同租户当日重跑时，无下游产物的旧 draft 自动
  让位（evidence 记 superseded），今日热点=今日最新一批。
- **R1.5**（C）审阅交互：队列式逐条 定审/否决/跳过 + 键盘 A/S/X/Esc + 自动下一条；
  计数 chips 筛选、批量定审/否决、NEW 徽标、相对时间；表格存档行内可审、点行展开。
- **R1.6** 发布数据反哺选题评分。**不做**（用户裁定）——评分只由内容本身决定；
  发布数据不进系统台账（见 R6）。
- **R1.7**（C）检索降级必须可见：命中条数或未生效原因展示在选题详情。
- **R1.8**（C）**话题雷达**（抖音话题监控，区别于 R1.2 否决的大众热榜）：定时巡检指定话题的
  新视频（去重），产出**飙升通知**与**低粉高赞清单**（硬阈值：粉丝<10万、赞粉比≥2），
  人工判断后加入拆解库；雷达话题 ID 全局唯一（R11.3）。

## R2 脚本工场

- **R2.1**（D+C）三版口播生成：**按选题类型自动选择最合适的三个范式**（悬念/数字/反共识
  为基础范式库，可扩展）；篇幅两档（2026-10-09 流量诊断定档：自有账号 40~70s 中位播放 441、<40s 仅 248）——**240~320 字（50~70 秒黄金档，默认）**与长版 600~900 字（2~3 分钟，视频号场景），生成时可选；
  硬约束=前 3 秒钩子点名受众+痛点、中段可验证证明（案例/数字/交付物）、
  **结尾自然收尾（不刻意 CTA，禁引导话术）**、
  **合规红线（写死）：禁绝对化承诺（最好/第一/保证收益等）、禁夸大宣传、实事求是**、
  **人设回扣（写死）：每条的证明环节必须落到可验收交付（验收单/可量化结果）**。
- **R2.2**（D+A）口播结构模板库 CRUD（默认模板 hook→pain→solution→proof→cta）；
  生成时自动选用使用次数最多的模板。
- **R2.3**（D+C）批判打磨：刻薄评审逐版挑刺并重写，可反复；critique 追加进 notes；
  **生成后自动先打磨一轮**再进定稿队列（仍可手动追加）。
- **R2.4**（D）定稿三产物：提词器文本（`/`停顿、`**`重音、按呼吸分段）、
  分镜（≥3 镜头含 B-roll 关键词）、标题候选（抖音×2 / 视频号×1 / 封面大字≤12 字）。
- **R2.5**（C）定稿交互：三版同屏对比，1/2/3 选版，A 定稿 / P 打磨 / S 跳过。

## R3 同行监测与拆解库

- **R3.1**（C）同行账号管理与监测（独立「同行监测」页，拆解库页只管作品审阅）：
  账号增删改查与启停；单号扫描 + 一键全量扫描；上次扫描时间与扫描历史
  （路线/降级原因必须可见）；账号实测评分展示（相关性/质量/综合，
  质量分 <7.5 移除监控，口径见 MRD §2.1.1）；每号拆解统计联动（近 7 天/累计）。
  添加账号支持**链接自动识别**：贴视频或主页链接，自动反查昵称与主页回填。
- **R3.2**（C+调研）扫描主路线免登录：贴作者任意一条视频链接（锚点视频模式）
  或主页链接；下载与列表全部走浏览器拦截；降级原因必须可见。
- **R3.3**（D）贴链接在线拆解（免登录）+ 本地视频/音频上传拆解。
- **R3.4**（C）每账号每次最多排队 **10** 条新视频（控 LLM 成本），按视频 ID 去重。
  **拆解完即删**：媒体文件在拆解成功后自动删除（重拆解自动重新下载，本地原文件删后需重新上传），
  磁盘不随拆解量无限增长。
- **R3.4b**（C）拆解报告增加**数据归因**维度：结合播放/点赞等数据拆解"为什么这条爆"。
- **R3.4c**（C）**定时自动扫描**：系统按计划周期自动执行同行扫描（无需手动点），
  依赖定时任务框架（见 X10）。
- **R3.6**（C）**关键词发现对标账号**：添加账号支持「搜账号」模式——输入关键词+方向，
  搜索引擎挖出抖音相关视频（绕开平台搜索登录墙）→ 免登录 反查作者与粉丝数，
  按粉丝数排序产出候选清单（持久化，待定夺/已加入/已忽略）；一键加入监测清单
  （分享主页链接，扫描链路直接可用）；已在清单的自动标记，已忽略的不重复推荐；
  风控样本自动跳过且原因可见。热门排序用真实粉丝数，不消耗 LLM。
- **R3.7**（C）**质量闸全自动拆解**（2026-10-28 全自动化裁定）：扫描发现的同行新作品按
  **内容热度分**（赞粉比×赞数量结合，0~10；门槛与每日上限设置页可调）自动批准进拆解
  （下载→ASR→LLM→选题候选自动进选题库 draft，候选带热度分），未达标行保留待定夺；
  话题雷达「低粉高赞」命中同口径自动进拆解，已在库不重复。拆解库日常无需人工巡视。
- **R3.8**（C）**两类号策略与拆解分叉**（2026-10-28；2026-10-28 修正：类型是**内容本身**
  的属性，拆解/选题时即判定，与账号粉丝量无关）：拆解 prompt 为**双模式判定式**——LLM 先
  判 content_type（leadgen=引导密集的获客内容；persona=观点/干货/人设内容），再按判定输出
  对应分析：persona 走内容质量拆解（结构/高光/可复刻点），leadgen 走**获客打法拆解**（内容
  模式/引导话术清单/CTA 密度与位置/转化路径/可复制打法卡）；判定结果回写样本行并随选题候选
  入库（脚本工场投放类型默认读它，可手动改）。获客号挖掘信号=**评论区求带密度**（求带/报名/
  私信类评论占比 ≥8% 判获客型，发现流程自动探测 Top3 样本并按获客优先排序）。
- **R3.9**（C）**脚本按投放账号类型分风格**（2026-10-28）：脚本工场生成时选投放账号类型
  （人设号/获客号，默认读选题来源类型）——人设号禁一切引导话术（现有红线）；获客号要求
  获客引导（结尾行动指令+利他包装的扣字/私信设计，合规红线仍约束产品承诺）；打磨按类型
  应用对应红线。
- **R3.5**（边界）视频号自动扫描：平台无公开网页接口，**不做**；本地上传拆解为替代路线。

## R4 视频生产线（不做）

- **R4.1~R4.5** 口播原片上传/ASR 对齐/剪映模板草稿/素材库/B-roll 匹配 **整块不做**（用户裁定）：
  成片路线：口播数字人（原 R10）已于 2026-10-29 整体退役，不经过剪映草稿剪辑；产线止于脚本与图文内容。
  storyboard 分镜（R2.4 定稿产物）保留为**拍摄/口播提示**，不再驱动草稿生成。

## R5 公众号

- **R5.1**（D）从定稿脚本（或直接从选题）生成长文，**双档位**（生成时可选，默认 feed）：
  **feed 公众号版**（1200~1800 字，信息流标题公式=人群+数字+冲突+可带走判断、开头即答案禁铺垫、
  判断式小节标题、金句收尾）；**deep 深度版**（3000~5000 字，铺垫式开头、机制拆解/方法框架/边界条件，
  判决句式标题、全文至少一个可转述的原创判断框架、术语必跟生活化类比、数字带体感锚点、
  关键知识点挂「人物+年代+冲突」一句话事实锚）。
  两档均**自然收尾**（不加转化引导话术）；风格库单选（**精选五视角**：深度研究/落地实践/问题深挖/对象解剖/方案对比，2026-10-03 自八视角收敛），默认「**自动**」——生成开头按选题素材自动挑选最合适的分析透镜（无效回落深度研究）。
- **R5.1a**（C）**数据论据国内源优先**（硬约束）：深研/脚本/长文大纲/长文分节/知识图解五处生成
  一律优先国内公开数据、行业报告、国内企业实践（注明来源与年份）；国外机构数据只在国内无同类
  口径时作补充，不作主锚点。
- **R5.4**（C）**一页纸知识图解**：成文后自动提炼全文生成一页纸知识图解 PNG（文字全部排版层
  渲染零错字，品牌角标取租户配置）追加至文末；文章页可手动（重新）生成（正文过短拒绝）。
- **R5.2**（D）人工改稿（md 编辑保存）→ 公众号内联样式渲染 → 一键复制 HTML。
- **R5.3**（C）写作队列交互；「不做长文」永久出口 + 可恢复。

## R6 发布台

- **R6.1**（D）发布物料包：抖音标题/备选、话题标签（LLM 生成）、视频号文案、
  封面大字（≤12 字）、公众号 HTML（文章类），逐项一键复制。
- **R6.2** 发布登记台账与数据补录。**不做**（用户裁定）——发布数据不进系统，
  效果在平台后台/微信侧看。
- **R6.3** 发布相关的待办队列。**不做**（随台账移除）；「不做长文」出口（R5.3）保留。
- **R6.4** sau 半自动上传。**不做**（用户裁定，集成移除）。
- **R6.5**（D1）发布永远人工。**不做**任何全自动发布。
- **R6.6**（C）**海报提示词工场**：把文章/任意内容转成即梦(Seedream)式「图文一体海报」的完整
  生成提示词（出图引擎在系统外，系统只产出提示词；LLM 失败回落关键词模板并标注 mode：
  llm / llm+template / template）。三个入口：配图位级单条、文章级整包、自由文本（贴大纲即用）；
  前端四落点：公众号配图位旁、文章操作区、发布台、流水线独立页。

## R7 工作台 / R8 设置

- **R7.1**（C）全流水线待办总览（口径含忽略项），点卡片直达对应队列。
- **R7.2**（D）服务/数据库/LLM/本地依赖/外部容器状态可视（平台状态卡位于管理后台·总览，2026-10-02 自工作台迁入）。
- **R7.3**（C）**抖音采集探针**：定时（15 分钟）主动微型爬取真实视频页并按形态分类
  （正常/登录墙/验证码/代理断/浏览器错/无数据），状态翻转发系统通知；设置页采集卡
  （当前状态/历史/手动探测）；拆解提交时探针异常即预警。
- **R8.1**（C）设置页：LLM 通道状态与端点识别（套餐/按量）、写作模型与检索通道运行时切换
  （存数据库、立即生效）、**API Key 写入**（只写不读回）、真实调用体检。**仅平台管理员可见**（平台运营页，
  成员/租户管理员不渲染该入口）。
- **R8.2**（C）联网检索通道三选（ddg / auto / glm）运行时切换。
- **R8.3**（D+C）LLM 用量台账**按用途分账**（深研/脚本/拆解/长文/其他各花多少）+ 本地能力清单。

## R9 自我风格研究

- **R9.1**（C）**我的账号**：在同行监测中标记自有账号（kind=self），与同行账号共用
  免登录 扫描管线与链接自动识别；不参与同行评分，扫描全量时排除（走自我研究链）。
- **R9.2**（C）**风格拆解**：我的账号每条新视频自动下载→ASR→风格拆解——只提取**形式
  特征**（开场模式/句式节奏/口头禅/语气强度/论证习惯/收尾方式/代表原句），
  不判断内容价值、不产生选题候选；产出存 self_videos。
- **R9.3**（C）**风格画像**：滚动汇总逐条风格标注生成画像（摘要 + 特征标签 + 代表原句，
  标注"基于 N 条视频"）；**保留历史版本**，可看风格演化；每新增 ≥5 条自动重算，
  也可手动触发；旧画像作为增量演化参考。
- **R9.4**（C）**脚本注入**：脚本生成与打磨的 Prompt 注入最新画像（摘要+标签+代表原句），
  使输出贴近本人风格；注入默认**开启**，可在脚本工场按次关闭；**无画像时回落到
  内置人设文案**（降级可见）。
- **R9.5**（C）**「我的风格」页**（情报组）：画像卡（摘要/特征标签/代表原句/基于条数/版本）、

## 使用场景（产品怎么被用）

**核心心智**：打开工作台看欠账 → 点卡片进队列 → 按键清空 → 表格里查历史。

### 日常工作流（建议节奏）

```
① 定时自动扫描同行（R3.4c）→ 新视频自动拆解 → 选题库队列清审（A/S/X）
② 随时有 idea：选题库顶部输入一句话回车（1~2 分钟出报告+评分）
③ 定审选题 → 脚本工场生成三版 → 对比定稿（顺手 P 打磨一轮更锋利）
⑤ 长文：公众号队列 A 生成 → 展开改稿 → 渲染 → 复制到公众号后台（发布人工）
⑥ 发布前：发布台生成物料包 → 复制标题/话题/封面字 → 人工发布（数据在平台后台看）
```

### 统一交互契约（X1 的用户视角）

- 队列快捷键：选题 `A定审/S跳过/X否决`；脚本 `1/2/3选版、A定稿、P打磨、S跳过`；
  其余页 `A主操作/S跳过`；全站 `Esc` 退出；输入框聚焦时自动屏蔽防误触。
- 「不做」出口：不做长文 / 不发布 / 不补数据 = 永久忽略，汇总屏可一键恢复。
- 慢操作有进度提示（定稿约 80 秒、打磨 3~6 分钟属正常）。

### 常见问题（FAQ）

| 现象 | 处理 |
|---|---|
| 深研显示"联网检索未生效" | DDG 偶有限流，报告仍产出（降级已明示）；要更稳在设置页切 auto/glm（需智谱按量余额） |
| 在线拆解/扫描失败 | 可能触发验证码，重试；仍失败用本地视频拆解（失败原因在任务详情可见） |
| 假数据进了评分 | 删记录并把选题分回到 score_breakdown.base |
